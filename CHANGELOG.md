# Changelog

All notable user-visible changes to the EmulatorJS TOS application package.

## 1.9.2-1 — 2026-11-12

### Added
- First release. EmulatorJS (`linuxserver/emulatorjs:1.9.2`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8118 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/emulatorjsdocker/`.
